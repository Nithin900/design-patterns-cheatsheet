# Design Patterns Cheat Sheet

My Java design patterns notes, one card per pattern, in my own words.

**View it:** https://nithin900.github.io/design-patterns-cheatsheet/

## How to update

1. Open [`cheatsheet.md`](cheatsheet.md) and click the ✏️ pencil (or use **✏️ Edit** on the site).
2. Copy the template from the top of the file, add a new `## Pattern name` section, fill it in.
3. Click **Commit changes**. The site updates in about a minute.

Each `## ` heading becomes a card. `Category:` sets the colored tag (Creational / Structural / Behavioral), and lines like `Problem:` or `Use when:` are shown in bold.
